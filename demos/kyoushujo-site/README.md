# 自動車教習所サイト（デモ）

`index.html` をブラウザで開くだけで動きます。ビルド・インストールは不要です。

画面上部で**デザイン2案を切り替え**られます。HTML構造とデータは2案とも完全に同じで、
配色・角の丸み・書体・見出しの出し方だけを設定で差し替えています。
「設計意図をひらく」から、各案が何を狙っているかを確認できます。

| 案 | 方向性 | 想定 |
|---|---|---|
| 案A｜ブライト | 彩度の高い青＋丸ゴシック、CTAはオレンジ | 10代〜20代前半とその保護者。「怖そう」を先に下げる |
| 案B｜ナチュラル | 落ち着いた緑＋明朝、直線的な罫線 | 社会人・再取得層。料金と実績を比較検討する人 |

## 実装している機能

## 問い合わせを取るための設計

教習所サイトで問い合わせ前に離脱する最大の理由は、**「結局いくらかかるのか分からない」**です。
「◯◯円〜」の表記だけでは、割引・所持免許による免除・追加教習料を足し引きした後の
自分の金額が分からず、比較のために電話をかけるか、そのまま他校に移ります。

そこでこのデモは、**料金シミュレーターを事実上のトップコンテンツとして扱っています**。

**1. 総額を出す**
入学金・学科・技能（規定時限）・検定料・教材費・適性検査料を含んだ税込総額を表示し、
別途かかるもの（本試験手数料・追加教習料の単価）も同じ画面に書いています。
金額を先に出すと問い合わせ件数は絞られますが、**予算の合った問い合わせだけが残ります**。

**2. 内訳を見せる**
割引がいくら効いたかを行単位で表示します。「学生割引で11,000円下がった」が見えると、
入力を1つずつ試す動きが生まれ、そのまま仮申込に進みます。

**3. 分割払いの月額を併記する**
30万円は一括で見ると止まりますが、月々の金額なら判断できます。学生とその保護者に効きます。

**4. 空き状況を先に出す**
「×」の日を先に見せることで、締切間際の申し込みが動きます。
表の記号から仮申込へ直接進めるようにしています。

**5. 仮申込は3分・費用ゼロと明記する**
電話をかけたくない層の受け皿です。完了画面で必要書類を案内し、
住民票の不備（本籍地の記載なし・マイナンバー入り）で入校日に手続きできない事故を先に潰します。

公開後は「シミュレーターの操作回数」と「そこからの仮申込数」を対にして見ます。
どの条件で離脱しているかが分かれば、次に見直す価格表とプラン構成が決まります。

## 設定オブジェクトで他校にも転用できます

校名・電話・配色・コース・料金・割引・入校日・送迎バス・お客様の声・FAQ は、
すべてファイル冒頭の `SITE` と `DESIGNS` に集約しています。コードには一切べた書きしていません。

```js
const SITE = {
  school:    { name: "みなみ野自動車学校", tel: "0120-48-7200", ... },
  licenses:  [ { id, label, cat, days, lessons, price: { commute, camp } }, ... ],
  styles:    [ 通学 / 合宿 ],
  plans:     [ レギュラー / 優先予約 / 短期集中 ],
  discounts: [ 学生割引 / 早割 / グループ割 / 卒業生割 ],
  held:      [ 所持免許による学科免除の減額 ],
  intakes:   [ { date, stock: { at: "○", mt: "△", ... } }, ... ],
  buses:     [ { name, stops, times }, ... ],
  reasons: [...], flow: [...], voices: [...], faq: [...], news: [...],
};
const DESIGNS = { bright: {...}, natural: {...} };  // 配色・角丸・書体だけを保持
```

- **コースを1件追加する**と、料金シミュレーター・空き状況の表・仮申込の選択肢の3か所に自動で反映されます
- **配色を変える**のは `DESIGNS` の色を差し替えるだけです（2案の中間や、A案の色でB案の書体、といった組み合わせも可能です）
- **入校日の空き状況**は `intakes` の1箇所で、ヒーローの表示と表とフォームの選択肢に同時に反映されます

WordPress で構築する場合は、この構造をそのままカスタム投稿タイプ + カスタムフィールドに対応させます。

| このデモの構造 | WordPress側 |
|---|---|
| `licenses[]` | カスタム投稿タイプ `course`（料金・時限数・最短日数をカスタムフィールド化） |
| `intakes[]` | カスタム投稿タイプ `intake`（管理画面から ○△× を更新 → サイトに即反映） |
| `buses[]` / `faq[]` / `voices[]` | 繰り返しフィールド（ACF） |
| `school` / `DESIGNS` | テーマオプション（1箇所直せば全ページに反映） |
| Web仮申込フォーム | Contact Form 7 / Snow Monkey Forms + 自動返信・管理者通知 |
| 料金シミュレーター | 料金テーブルをオプションに保持し、JSで計算（サーバー側でも再計算して整合を担保） |

## 技術構成

- React 18 + Babel Standalone + Tailwind CSS（すべてCDN、1ファイル完結）
- localStorage 不使用。ページを閉じると入力内容は残りません
- フォームは送信内容をどこにも保存・送信しません（入力チェックのみ動作します）
- スマホ幅まで対応（画面下にCTA固定、表は横スクロール）

※ 校名・料金・時刻・卒業生の声はすべて架空のものです。写真は色付きの枠で代用しています。
