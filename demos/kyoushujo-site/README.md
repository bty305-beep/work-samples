# 自動車教習所サイト TOPデザイン案（デモ）

`index.html` をブラウザで開くだけで動きます。ビルド・インストールは不要です。

教習所ホームページのリニューアル提案用に作った、TOPページ1枚のデザイン案です。
画面上部で**案A・案Bを切り替え**られます。右上の「設計意図をひらく」から、各案の狙いを確認できます。

---

## この案が解いている問題

ご依頼の核は「若者に刺さるデザイン」と「保護者が安心できる料金の明朗さ」の両立です。
この2つは同じ表現では成立しません。写真とスピード感で振り切ると保護者は不安になり、
条件と数字で固めると学生は読み始めません。

そこで**トーンを混ぜず、ページの上下で読み手を分けました**。

| 位置 | 読み手 | 書き方 |
|---|---|---|
| ファーストビュー〜コース一覧 | 学生ご本人 | 取得までの期間、学生プラン、キャンペーン。「いつ取れるか」を先に出します |
| 料金セクション以降 | 保護者の方 | 総額・追加料金の有無・支払い方法・キャンセル規定 |

切り替わる位置（コース一覧と料金セクションの間）に、**読み手が入れ替わる設計であることを説明する帯**を置いています。
高校生の場合、申込みを決めるのはご本人でも、支払いを判断するのは保護者の方であることが多いためです。
各セクションの見出しにも「この区間は誰に向けて書いているか」のラベルを出しています。

---

## 2つのデザイン案

| | 案A｜写真主体・勢い重視 | 案B｜情報整理・比較重視 |
|---|---|---|
| 優先するもの | 学生の共感 | 保護者の納得 |
| ファーストビュー | 全画面写真＋大きなキャッチと3つの数字 | 左に訴求、右に**学生プランの総額表**を配置 |
| コース一覧 | 写真カード（どんな人向けかを先に読ませる） | 比較表（並べて比べられることを優先） |
| 配色 | ビビッドなオレンジ＋黒（角丸を大きく） | ブルー＋グリーン（角丸は控えめ、罫線主体） |
| トレードオフ | 学生の反応は取りやすいが、保護者は料金まで到達しないと安心材料に触れない | 保護者は最初の画面で判断できるが、学生への引きは案Aより弱い |

下半分（料金・支払い・キャンセル・FAQ）の構成は2案とも同じです。変えているのは上半分の強さと、料金の見せ方です。

---

## 構成（TOP1枚）

1. **ファーストビュー** — 最短14日・追加料金0円・キャンペーン額の3つの数字
2. **キャンペーン** — 学生応援 / 友だち割 / 早割（併用可であることを明記）
3. **選ばれる理由** — 4点。各項目に「保護者の方へ」の一文を添えています
4. **コース一覧** — 普通車AT/MT、普通二輪、大型二輪、準中型
5. **★ 読み手の切り替え帯** — ここから保護者向けに切り替わることの説明
6. **料金** — コース別の総額、含まれるもの、**含まれない公的費用**、支払い方法4種、キャンセル規定
7. **免許取得までの流れ** — 6段階。保護者への進捗連絡についての注記つき
8. **よくある質問** — 保護者の不安（追加費用・両立・返金・進捗連絡・事故対応）から並べています
9. **問い合わせ導線** — 電話とフォームを併記。フォームは入力形式の検証つき

## 料金の書き方について

「追加料金なし」と書く以上、**教習料金に含まれない公的費用も同じ場所に金額付きで書いています**
（仮免許・本免許の試験手数料など、合計6,650円）。ここを書かないサイトは、
あとで金額が動いたと受け取られ、その時点で信用を失います。

そのうえで「総額 ＋ 公的費用 ＝ 実際に必要な金額」を1行で計算して見せています。

## 元サイトの課題への対応

| リニューアルの背景 | この案での対応 |
|---|---|
| ページ遷移が悪い | 判断に必要な情報をTOP1枚で完結させ、下層は詳細確認だけにします |
| スマホファーストでない | スマホ幅を先に組み、電話とフォームへの導線を画面下に常時固定 |
| ターゲットが明確でない | 上下で読み手を分け、どちらにも中途半端にならない構成に |

## 技術構成

- React 18 + Babel Standalone + Tailwind CSS（すべてCDN、1ファイル完結）
- localStorage 不使用。フォームの送信内容はどこにも保存・送信しません（入力チェックのみ動作します）
- 校名・コース・料金・支払い方法・FAQ は、ファイル冒頭の `SITE` オブジェクトに集約しています
- 配色とレイアウトの方向性は `PLANS` オブジェクトに集約し、CSS変数経由で切り替えています

実案件は WordPress（オリジナルテーマ）での構築を想定しています。
`SITE` の構造をそのままテーマオプション + カスタムフィールドに対応させ、
コース・料金・FAQ は繰り返しフィールド、フォームは Contact Form 7 等で実装します。

※ 画面上部の案切り替えバーは提案用のUIです。実サイトには載りません。
※ 校名・料金・実績・写真はすべて架空のものです。写真は色付きの枠で代用しています。
