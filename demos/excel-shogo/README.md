# Excel突合の自動化 — `demos/excel-shogo/`

銀行の入金明細と帳簿を突き合わせ、**一致・不一致・要確認**の3分類で出すデモです。`index.html` をブラウザで開くだけで動きます（インストール不要）。

**▶ [ブラウザで開く](https://bty305-beep.github.io/work-samples/demos/excel-shogo/)**

「表記がそろっていないから機械では突合できない」と言われる作業ですが、そろえ方（正規化ルール）を決めれば大半は自動で片づきます。それを、説明ではなく画面の数字で確認できるようにしたものです。

---

## この画面でできること

### 【1】突合する2つの表を左右で見る

開いた時点でサンプルデータが入っています。左が銀行の入金明細（30行）、右が売掛帳（30行）。実務でよくある崩れ方をそのまま入れてあります。

### 【2】「突合する」を押すと3分類で出る

| 分類 | 意味 |
|---|---|
| 一致 | 取引先・日付・金額が、決めたルールの範囲ですべて合っている。そのまま消し込める |
| 不一致 | 相手の行は見つかったが、金額または日付が合わない。差額と日数を表示する |
| 要確認 | 片方にしかない、名前が似ているだけで同じ会社と断定できない、同じ条件の候補が複数ある。機械が決めず人に回す |

### 【3】なぜその分類になったかを行ごとに表示する

「金額が違います。差額 660円」「日付が1日ずれています」「表記ゆれを正規化して名寄せしました（「（株）サンプル物流」と「株式会社サンプル物流」）。効いたルール：…」というように、**判断の根拠を1行ずつ日本語で出します。** 中身の見えない自動処理は、経理の現場では使われないためです。

### 【4】正規化ルールをその場で切り替えられる

チェックを外すと、そのルールを使わずに突合しなおします。結果は即座に変わります。

- 前後・途中の空白を無視する
- 全角と半角を同一視する
- 「株式会社」「（株）」「カブシキガイシャ」を同一視する
- 記号・括弧と「※8月分」などの付記を無視する
- 日付の書式の違いを吸収する（`2026/08/31` `2026-08-31` `20260831` `2026年8月31日` `R8.8.31`）

あわせて**金額の許容差（円）**と**日付の許容ずれ（日）**も変えられます。

「正規化なしで突合する」を押すと全ルールを外した状態になり、「推奨の設定に戻す」で戻ります。同梱データでの結果は次のとおりです。

| 設定 | 一致 | 不一致 | 要確認 |
|---|---:|---:|---:|
| 正規化なし | 10件 | 8件 | 22件 |
| 推奨（全ルール） | 20件 | 6件 | **7件** |

**要確認が22件から7件に減ります。** 集計タイルには常に「正規化なしの場合は何件か」を併記しているので、ルールが何件分の目視を消しているかがその場で分かります。

### 【5】手作業との比較

1か月の件数と1件あたりの目視秒数を入れると、削減時間が出ます。**突合結果の比率（人が見る行の割合）をそのまま当てはめて計算**しています。画面の数字が変われば、削減時間も変わります。

## 同梱しているサンプルデータの崩れ方

きれいなデータだけでは意味がないため、次の崩れ方を入れてあります（すべて架空のデータです）。

| 崩れ方 | 該当行 |
|---|---|
| 完全に一致 | 丸尾工業、ハヤシフーズ、新星ロジスティクス ほか |
| 金額が1円違う | 青葉システム（458,330 / 458,331） |
| 金額が振込手数料の分だけ違う | 富士見テック（329,340 / 330,000　差660円） |
| 金額の桁を打ち間違えている | さくら物産（780,000 / 78,000） |
| 金額が全角で入っている | ひまわり食品（`１４８，５００`） |
| 日付が1日ずれている | みどり印刷、コスモ商事、まつもと商会（月をまたぐケース） |
| 「株式会社」と「（株）」 | サンプル物流 |
| 「株式会社」と「カブシキガイシャ」 | 大和紙業（前株・後株の違いも同時に発生） |
| 全角と半角の混在 | ＡＢＣ商会 / ABC商会、ＭＫフーズ株式会社 / MKフーズ(株) |
| 半角カナ | ミナトフーズ株式会社 / `ﾐﾅﾄﾌｰｽﾞ(ｶ` |
| 摘要に余計な空白と記号 | 山田商店 / `山田　商店 ※8月分` |
| 日付の書式違い | `R8.8.14`、`2026年8月25日`、`20260831`、`2026-08-11` |
| 名前が似ているだけの別会社 | セイワ電機 / セイワ電気（自動一致にせず要確認へ） |
| 同名・同額の取引が重複 | イロハ設備が帳簿に2件、明細に1件 |
| 明細にしかない行 | 振込手数料、電気代の引き落とし、帳簿にない入金 |
| 帳簿にしかない行 | 三村建材（未入金）、田中電設（現金回収） |

## 突合の考え方

1. **正規化した取引先名が同じ行どうしを突き合わせる。** 候補が複数あるときは、金額と日付がもっとも近い行を選びます
2. **残った行は、名称の近い相手を候補として出す。** 一致度が基準（初期値 68％）を超えても**自動では一致にしません**。「セイワ電機」と「セイワ電気」は、別会社かもしれないためです
3. **それでも残った行は、片方にしかない行として要確認に回す**

**迷ったら要確認に落とす**方針にしています。突合作業で困るのは、目視の手間よりも、誤って消し込まれた行が後から見つかることのほうだからです。

## 設定の差し替え方

突合のルールは、すべて `index.html` の冒頭の設定オブジェクトにまとめてあります。**画面のコードは列名を直接持っていません。**

```js
const RECON_CONFIG = {
  left: {                          // 突合の起点にする表
    label: "銀行入金明細",
    keyField: "摘要",              // 突合の鍵にする列
    dateField: "日付",
    amountField: "金額",
    kindField: "区分",             // 対象外の行を判定する列（なければ null）
    kindTarget: "入金",
    columns: [ /* 画面に出す列と並び順 */ ],
  },
  right: { label: "売掛帳（帳簿）", keyField: "取引先", /* … */ },

  tolerance: { amountYen: 0, dateDays: 0 },   // 許容範囲
  similarThreshold: 0.68,                      // 名寄せ候補として出す一致度の下限
};
```

ここを差し替えるだけで、次のような突合にもそのまま使えます。

- 請求書と入金明細（鍵＝請求先／振込依頼人）
- 受注一覧と出荷一覧（鍵＝注文番号）
- 在庫表と棚卸表（鍵＝商品コード、金額の代わりに数量）

正規化ルールも `KEY_RULES` という配列で持っており、1件書き足せば画面のチェックボックスにも自動で並びます。業種ごとの表記ゆれ（屋号の略記、支店名の付記など）は、ここに足して対応します。

## 実際にお渡しするもの

この画面は**動作を確認していただくためのもの**です。ブラウザの中だけで動いており、Excelファイルの読み書きはしていません。

実際の納品物は、**お手元のExcelファイル2つに対して同じ処理を行うPythonスクリプト**です。

| | デモ画面 | 納品物 |
|---|---|---|
| 入力 | 埋め込みのサンプルデータ | お手元のExcel / CSV |
| 出力 | 画面表示 | 分類ごとにシートを分けたExcelファイル |
| 設定 | 画面のチェックボックス | 設定ファイル（JSON） |
| 実行 | ボタン | コマンド1行、またはダブルクリック |

元のファイルは書き換えません。設定ファイルの形は次のとおりで、列名や許容範囲が変わっても、ここを直すだけで済みます。

```json
{
  "left":  { "path": "銀行明細.xlsx", "key": "摘要",   "date": "日付", "amount": "金額" },
  "right": { "path": "売掛帳.xlsx",   "key": "取引先", "date": "日付", "amount": "金額" },
  "rules": { "space": true, "width": true, "corp": true, "symbol": true, "date": true },
  "tolerance": { "amount_yen": 0, "date_days": 0 },
  "output": "突合結果_2026-08.xlsx"
}
```

同じ考え方のPythonスクリプトとサンプル出力は、[Excel業務の自動化キット](https://github.com/bty305-beep/work-samples/tree/main/excel-kit)（`jobs/reconcile.json`）に置いています。

## 技術構成

- 1ファイル完結のHTML。React 18 + Babel Standalone + Tailwind をCDNから読み込みます
- Babel は `registerPreset` で classic runtime を指定しています
- `localStorage` は使用していません。ページを開き直すと初期状態に戻ります
- スマートフォン幅まで対応。表は横スクロールします
- 外部への通信はCDNの読み込みのみで、データの送信は行いません

## 注記

掲載している会社名・日付・金額は、すべてデモ用の架空のものです。実在する企業・取引とは関係ありません。削減時間などの数値も、入力した条件から計算した想定値です。
