# 士業サイト リニューアル デモ

税理士事務所を想定した、サイトリニューアルのデモです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。

**▶ [ブラウザで開く](https://bty305-beep.github.io/work-samples/demos/shigyo-site/)**

---

## 収録している3画面

画面上部のタブで切り替えられます。

| | 画面 | 内容 |
|---|---|---|
| ① | トップページ | ファーストビュー、お知らせ、取扱業務、選ばれる理由、事務所紹介、料金の目安、ご相談の流れ、よくある質問、問い合わせ導線 |
| ② | 下層ページのベース | 「相続税申告」を例にした1枚。パンくず・目次・本文・関連ページ・問い合わせ導線を含みます |
| ③ | 見出し・パーツのパターン集 | H2〜H5、リスト、注意書き、表、よくある質問、引用、ボタン、目次、カラーパレット |

## このデモで見ていただきたいところ

下層ページが多いサイトで実際に効いてくるのは、トップページの見た目よりも
**「他のページを同じ品質で増やせるかどうか」**です。そのため、③のパターン集を成果物の中心に置いています。

- **②の下層ページは、1枚コピーすれば他の業務ページになる構造**にしています。
  ページの中身は `SUBPAGE` オブジェクトにまとまっていて、目次・パンくず・関連ページは
  そこから自動で組み上がります。見出しを増やしても、目次を手で直す必要はありません。
- **③のパーツはすべて②で実際に使っているもの**です。見本のためだけに作った飾りはありません。
- 各パーツの下に、投稿画面のどの操作でその見た目になるかを書き添えています。

## 色・文字サイズ・余白の変更

ファイル冒頭の `THEME` オブジェクト1か所にまとめています。
事務所のカラーに合わせる場合、ここだけ書き換えれば3画面すべてに反映されます。

```js
const THEME = {
  color: {
    primary: "#16324f",  // 基調色（濃紺）
    accent:  "#a3813c",  // 差し色（金茶）
    ...
  },
  font:  { h1: "...", h2: "...", lineHeight: "1.9", ... },
  space: { section: "...", container: "1080px", ... },
};
```

WordPress化する際は、この値をテーマ設定（`theme.json`）へそのまま移します。
投稿画面の色選択にもここで決めた色だけが並ぶため、ページごとに色がばらつくことを防げます。

## 本デモの位置づけ

**本デモはデザインと構造の確認用です。実装はWordPressテーマとして行い、
見出しやリストは投稿画面から選択できるブロックとして登録します。**

- 画面上部の切り替えタブは3画面をまとめてご覧いただくためのもので、実際のサイトには含まれません。
- 掲載している事務所名・料金・実績はすべてサンプルです。
- ラフデザインをいただければ、その構成に合わせて作り替えます。
