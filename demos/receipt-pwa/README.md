# 領収書まとめ（基礎機能版）

レシート・領収書をスマートフォンで撮影し、**1つのPDFにまとめて**、**会計ソフト取込用のCSVを書き出す**ためのアプリです。
弥生・マネーフォワード・freeeの3形式に対応しています。

インストール・アカウント登録・APIキー・環境構築は一切不要です。
配布したURLをスマートフォンのブラウザで開けば、その場で使えます。

> **撮影した画像と入力した内容は、どこにも送信されません。**
> 画像の縮小、PDFの組み立て、CSVの生成、Shift_JISへの変換まで、すべて端末のブラウザの中で完結します。
> サーバーへの送信も、外部サービスの呼び出しもありません。通信が切れていても同じように動きます。

---

## 使い方

| | 操作 |
|---|---|
| 一 | **撮影**　「カメラを開く」を押してレシートを撮る。続けて何枚でも撮れる |
| 二 | **入力**　1枚ずつ、日付・金額・取引先・勘定科目・税区分を手で入れる |
| 三 | **書き出し**　ファイル名を決めて、PDFとCSVを保存する |

日付には撮影した日が最初から入っています。違う場合は書き換えてください。

### ホーム画面に追加する

- **iPhone（Safari）**　共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**　メニュー → 「アプリをインストール」／「ホーム画面に追加」

追加すると、ブラウザのアドレス欄のない画面で起動します。
一度開いたあとは、**通信できない場所でも起動して使えます**（機内・地下・電波の届かない現場など）。

## 画面の構成

| 画面 | 内容 |
|---|---|
| 撮影 | 端末のカメラを画面内に開き、続けて撮影する。すでに撮ってある写真からも追加できる |
| 入力 | 1枚ごとの札に、日付・金額・取引先・勘定科目・補助科目・税区分・摘要を入力する |
| 書き出し | PDFの作成と、CSVの書き出し（形式・文字コード・ファイル名を選ぶ） |
| 設定 | 勘定科目の候補、税区分の名称、freeeの相手科目、マネーフォワードの部門・インボイス |

## CSVの形式

3形式とも、**文字コードは Shift_JIS と UTF-8（BOM付き）から選べます。**
会計ソフト側で文字化けする場合があるためです。まず Shift_JIS を試し、化けるようならUTF-8に切り替えてください。

### 弥生（スマート取引取込）

| 列 | 入る値 |
|---|---|
| 識別フラグ | `0` 固定 |
| 取引日付 | 日付（`2026/08/17` 形式）**必須** |
| 出金額(円) | 金額 **必須** |
| 入金額(円) | 空 |
| 摘要 | 取引先（未入力なら摘要） |
| 備考 | 勘定科目 / 補助科目 / 税区分 / 摘要 を ` / ` でつないだもの |

スマート取引取込のこの形式には勘定科目の列がありません。
そのため勘定科目・税区分は備考に入れています。取り込んだあと、弥生の画面で勘定科目を確定してください。

消費税率は**標準10%・軽減8%・対象外の3種**のみを扱います。

### マネーフォワード（仕訳帳）

`取引No` `取引日` `勘定科目` `補助科目` `部門` `取引先` `税区分` `インボイス` `金額(円)` `摘要` `タグ` `メモ`

部門とインボイスは「設定」で指定した値が全行に入ります。タグとメモは空です。

> **確認のお願い。** この12列は指定された仕様のとおりに実装しています。
> ただしマネーフォワードの仕訳帳インポートは、版によっては
> `借方勘定科目` `貸方勘定科目` のように借方・貸方を対で持つ列構成を求めることがあります。
> 実際の取込先で一度お試しいただき、列が合わない場合はお知らせください。列構成の変更はすぐに反映できます。

### freee（振替伝票）

`日付` `借方勘定科目` `借方補助科目` `借方取引先` `借方税区分` `借方金額` `貸方勘定科目` `貸方補助科目` `貸方取引先` `貸方税区分` `貸方金額` `摘要`

借方に経費の勘定科目、貸方に相手科目（初期値は「現金」）を置きます。
掛けで払った場合など、相手科目は「設定」で「未払金」などに変えられます。

## 勘定科目名についての注意

**勘定科目・補助科目・税区分は、取り込む会計ソフトに登録されている名称と文字列が完全に一致していないと、インポートに失敗します。**

- 全角と半角（`10%` と `１０％`）
- 空白の有無（`課税仕入 10%` と `課税仕入10%`）
- 言い換え（`損害保険料` と `保険料`）

いずれも別の名称として扱われます。

このアプリは標準的な勘定科目18件と、会計ソフトごとの税区分の名称を初期値として持っています。
そのまま一致するとは限りませんので、**会計ソフト側の科目設定を開いて確認し、「設定」画面で同じ表記にそろえてください。**
この注意は、関係する画面すべてに表示しています。

## データの扱い

- 撮影した画像と入力した内容は、**ページを開いている間だけ**端末のメモリに置かれます
- `localStorage` などへの保存は行いません。**画面を閉じる・再読み込みすると消えます**
- そのため、**PDFとCSVを保存してから閉じてください**。写真がある状態で閉じようとすると確認が出ます
- 端末の外に出ていくのは、利用者自身が保存したPDFとCSVだけです

## 基礎機能版に入っていないもの

次の機能は意図的に外しています。追加機能として別に用意します。

- OCR・文字認識（金額や日付の自動読み取り）
- 勘定科目の自動判定
- クラウド保存、ログイン
- 月別の自動整理、検索
- 振込データの出力

## 1枚ごとのデータ構造

今後の機能追加に備えて、基礎版では使わない項目も空の値で最初から定義しています。

| 項目 | プロパティ名 | 基礎版 |
|---|---|---|
| id | `id` | 使用 |
| 画像 | `image` | 使用（JPEGのデータURL） |
| 撮影日時 | `capturedAt` | 使用 |
| 日付 | `date` | 使用 |
| 金額 | `amount` | 使用 |
| 取引先 | `partner` | 使用 |
| 税区分 | `taxCategory` | 使用（`10` / `8` / `none`） |
| 勘定科目 | `account` | 使用 |
| 補助科目 | `subAccount` | 使用 |
| 摘要 | `description` | 使用 |
| 記帳状態 | `bookkeepingStatus` | 未使用（空文字） |
| 支払期日 | `dueDate` | 未使用（空文字） |
| 振込先 | `payee` | 未使用（空文字） |

## 技術的な条件

- React 18 + Babel Standalone + Tailwind をCDNから読み込む1ファイル完結。PWAに必要な `manifest.json` と `sw.js` のみ別ファイル
- Babelは `registerPreset` で classic runtime を指定
- PDF生成は jsPDF、Shift_JIS変換は encoding-japanese（いずれもCDN、版を固定）
- PDFの中の日本語は、canvasに描いた紙面を画像として貼り込んでいます。PDF側に日本語書体を埋め込む必要がなく、読み込む部品が軽くなります
- 画面の色・書体・余白は、リポジトリ直下の `index.html` の `:root` をそのまま使っています。新しいトークンは足していません。PDFの中の色と書体も同じ変数から読んでいます
- `localStorage` は使用していません
- 配信はHTTPS（GitHub Pages）を前提としています。サービスワーカーと端末カメラの利用にHTTPSが必要なためです

### サービスワーカーが保存するもの

画面を組み立てるためのファイル（`index.html`、`manifest.json`、アイコン、CDNの部品6点）だけです。
撮影した画像や入力した内容をサービスワーカーが保存することはありません。

部品の版を上げるときは、`sw.js` の `CACHE` の名前も合わせて変えてください。古い保存分が破棄されます。

## 動作を確認した範囲

Chromiumで実際に画面を動かし、次を確認しています。

- 写真の追加 → 入力 → PDF作成 → CSV書き出しまでの一連の操作
- 3形式のCSVの列と中身、引用符を含む取引先名の扱い、Shift_JIS変換の往復一致
- UTF-8を選んだときに先頭へBOMが付くこと
- サービスワーカーが12点すべてを保存し、**サーバーを停止した状態でも**起動・撮影・PDF作成・CSV書き出しができること

実機（iPhone・Android）での確認、および実際の会計ソフトへの取り込みは行っていません。
とくに次の2点は、最初の1回を実際の取込先でお試しください。

1. 各ソフトが求める列構成と、このアプリが出す列が合っているか
2. 勘定科目・税区分の名称が、取込先の登録名と一致しているか
