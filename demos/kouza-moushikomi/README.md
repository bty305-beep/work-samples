# 講座 申込フォーム ＋ 申込管理 — `kouza-moushikomi/`

オンライン講座の**受講申込フォーム**と、**申込から受講開始までを管理する画面**のデモです。

`index.html` をブラウザで開くだけで動きます。インストールもサーバーも不要です。

---

## 画面

上部のタブで2つの画面を切り替えられます。

### 1. 申込フォーム（受講希望者が見る画面）

- 入力項目は **氏名 / メールアドレス / 希望講座 / 支払い方法 / 連絡事項** の5つ
- 未入力・メール形式の誤りは、その場で赤く指摘します（送信してから気づく形にはしません）
- 送信すると完了画面になり、**実際に送られる自動返信メールの文面をそのまま表示**します
  - 支払い方法によって案内文が変わります（振込先 / 決済ページのURL / 払込票番号）
  - メール送信自体はサーバー側で行います。ブラウザからは送信しません

### 2. 管理画面（運営者が見る画面）

- 申込一覧（申込日時・氏名・メール・希望講座・支払い方法・ステータス）
- ステータスは **申込受付 → 入金確認 → 受講開始** の3段階。プルダウンでその場で変更できます
- 上部にステータス別の件数と、講座別の申込数。件数カードはそのまま絞り込みボタンになります
- 氏名・メールアドレスの部分一致検索
- CSV書き出し（**BOM付きUTF-8**なのでExcelでそのまま開けます。書き出すのは**表示中の行のみ**）

フォームから送信した申込は、そのまま管理画面の一覧に並びます。

---

## 差し替えるところ

**講座・支払い方法・ステータス・自動返信メールの文面は、すべてファイル冒頭の `CONFIG` にまとまっています。**

| 設定 | 内容 |
|---|---|
| `CONFIG.courses` | 講座名・受講料・日程。増減させるとフォームの選択肢・集計・CSVがすべて追従します |
| `CONFIG.payments` | 支払い方法と、方法ごとの案内文・入金確認までの目安 |
| `CONFIG.statuses` | 申込から受講開始までの段階。4段階以上に増やす場合はここに足します |
| `CONFIG.mail` | 自動返信メールの件名と本文。差し込み項目は `{name}` `{course}` のように書きます |

画面のコードは触りません。別の講座・別の運用に変えるときは、この1か所だけを書き換えます。

---

## デモの制約

- データはブラウザ内のみで保持します。再読み込みすると初期状態（ダミー8件）に戻ります
- メールは送信されません。完了画面に文面を表示するところまでです

実案件では、申込データはデータベースに保存し、自動返信メールはメール配信サービス経由でサーバー側から送信します。
